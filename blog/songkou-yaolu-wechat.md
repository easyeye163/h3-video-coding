# 当千年古镇遇上AI仙侠：《嵩口镇妖录》如何用大模型重写文旅短剧的生产方式

> 一座藏在福建深山里的千年古镇，一群AI智能体协作的开源项目，一部用文生图、图生视频全链路生成的玄幻仙侠短剧。当真实历史遇上虚构仙侠，当传统文旅遇上AI生产力，会碰撞出怎样的火花？

---

## 一座古镇，两个世界

福建永泰嵩口，闽中山间的千年古镇。这里有南宋著名词人张元干的故里，有明清时期的120多座古民居，有石板铺成的鹤形路，有三重防御的万安堡，有"四水归堂"的用坦厝天井。

但很少有人知道——在另一个平行世界里，嵩口是**鹤鸣宗**封印上古凶兽穷奇的大阵驻地。

![嵩口全景仙侠化](https://cdn.jsdelivr.net/gh/easyeye163/h3-video-coding@main/images/songkou_3d_scenes/songkou_panorama_xianxia.png)
*嵩口古镇全景·仙侠化版本 — 屋脊灵光流转，群山间隐现灵气脉络*

这就是《嵩口镇妖录》的核心设定：**每一个真实地标，都是仙侠世界里的一个阵眼**。

| 真实地标 | 仙侠阵眼 | 功能 |
|:---|:---|:---|
| 万安堡 | 大阵核心 | 三重城墙对应三层封印，主镇压穷奇残魂 |
| 鹤形路 | 灵脉 | 整条路由鹤形石板铺成，引导灵气流动 |
| 用坦厝天井 | 聚灵阵 | 四水归堂格局汇聚天地灵气 |
| 龙口祖厝 | 守护者居所 | 曾氏一族世代守护大阵秘密 |
| 德星楼 | 观星台 | 夜观星象，监测大阵运转状态 |
| 古榕树 | 阵眼之根 | 千年古榕根系深入地脉，稳固大阵 |

这种"一实一虚"的映射不是简单的蹭热点——它意味着**每看一集短剧，等于认识一个真实的文旅景点**。观众为剧情而来，却被真实的古镇历史和建筑智慧留住。

## 三大创新：重新定义短剧生产

### 创新一：AI 全链路生成，从文字到成片

传统短剧制作需要编剧、分镜、选角、服化道、拍摄、后期……动辄数十人团队、数月周期。

而《嵩口镇妖录》的生产链路是这样的：

```
剧本 → 文生图（角色三视图 + 场景概念图）
     → 图生图（仙侠化风格迁移）
     → 文生视频（六段式 Full-Reference 提示词）
     → 声音设计（多角色音色一致性）
     → 剪辑成片
```

全程基于 **MiniMax H3** 视频模型和 **RunningHub** 工作流平台，所有素材和成片都通过 GitHub 仓库管理。

**角色一致性**：通过三视图参考图 + 六段式提示词中的 `<Picture>` 引用机制，确保角色在不同镜头、不同场景下面部、服装、体型不漂移。

**场景一致性**：每个地标先出仙侠化概念图，后续所有镜头的场景都基于概念图做参考，保证建筑形态和光影风格统一。

### 创新二：真实文旅 × 仙侠IP的双轮驱动

大多数AI短剧的通病是——看完就忘，没有落脚点。

《嵩口镇妖录》选择了完全不同的路径：**所有仙侠场景都有真实地理坐标**。

![万安堡仙侠化](https://cdn.jsdelivr.net/gh/easyeye163/h3-video-coding@main/images/songkou_3d_scenes/wan_an_castle_xianxia.png)
*万安堡·仙侠化版本 — 石墙高耸，封印符文裂纹蔓延，雷云汇聚*

观众看完万安堡弹孔那段戏，可以真的去嵩口找到这座三层防御的古寨堡，亲手触摸墙上的弹孔。这种"剧里剧外联动"的体验，是纯虚构内容无法提供的。

对于文旅推广来说，这更是一种降维打击——不再是干巴巴的景点介绍，而是用剧情和角色把观众"拉进"古镇。

### 创新三：开源仓库 + 多智能体协作

整个项目完全开源，托管在 GitHub 上。更特别的是，项目的日常维护和生产不仅有人类，还有多个 AI 智能体。

每个智能体有明确的分工：
- 有的负责写剧本和分镜
- 有的负责生成角色图和场景图
- 有的负责把提示词转成可执行的 API 命令
- 有的负责可视化看板的自动更新

它们通过同一个 GitHub 仓库协作——就像一个分布式的内容生产团队。

这种模式带来的好处是**可复制、可扩展**。你可以用同样的框架，给任何一个古镇、任何一处景区做一部专属的仙侠短剧。

## 未来规划

### 短期：12集正片上线

完成《嵩口镇妖录》第一季12集正片制作，每集60秒（4段×15秒）。B站、抖音、视频号全平台分发，配合嵩口古镇线下打卡活动。

### 中期：美食仙侠 × 文创衍生

古镇不只有建筑，还有美食。葱饼、蛋燕、礼饼、九重粿、滑肉汤——每一样都可以做仙侠化演绎。比如葱饼是"灵气补给丹"，礼饼是"阵眼封印糕"。

配合美食仙侠系列短片，可以开发真实的文创周边，让观众看完剧就能买到"同款"。

### 长期：可复制的古镇AI仙侠IP工厂

嵩口只是第一个。这套模式可以复制到任何一个有历史、有故事的古镇：

- 浙江乌镇 → 水乡妖族秘史
- 山西平遥 → 票号镖局的江湖传说
- 云南大理 → 南诏国的修仙传承

每个古镇都有自己的文化内核，AI 可以快速把它转化为可视化的仙侠故事。这不是简单的内容生产，而是**一种全新的文旅数字资产开发范式**。

## 写在最后

《嵩口镇妖录》不是一个完美的项目。角色动作还不够自然，剧情节奏还可以更好，AI生成的画面偶尔会有小瑕疵。

但它代表了一种可能性——

**当AI降低了内容生产的门槛，小地方也可以有自己的大IP。**

一座古镇，不需要千万级预算的影视公司，不需要流量明星，只需要一群热爱创作的人和几个AI智能体，就能做出一部属于自己的仙侠短剧。

这可能才是AI时代最让人兴奋的事情：**创造力，不再受限于资源。**
