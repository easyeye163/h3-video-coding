
# RunningHub API 节点配置总结

> **⚠️ 本文档是项目所有制作的基础，必须先阅读！**
> 所有项目（嵩口短剧、时空相遇、海边黄昏等）都基于以下 4 个 RunningHub 工作流制作。
> 不会调用这些工作流 = 无法制作任何内容。

## 0. API 使用说明（必读）

### API Key
- 32 位 API Key，存储在环境变量 `RUNNINGHUB_API_KEY` 中
- 消费级-会员 API Key 需基础版及以上会员；企业级不受限

### 提交任务端点
```
POST https://www.runninghub.cn/openapi/v2/run/ai-app/{appId}
```
- Header: `Authorization: Bearer ${RUNNINGHUB_API_KEY}` + `Content-Type: application/json`
- Body: `{"nodeInfoList": [...], "instanceType": "default", "usePersonalQueue": "false"}`
- 响应: `{"taskId": "xxx", "status": "RUNNING", ...}`
- ⚠️ 并发限制：同时只能有有限个任务运行，超限返回 `errorCode: 421`

### 查询结果端点
```
POST https://www.runninghub.cn/openapi/v2/query
```
- Body: `{"taskId": "xxx"}`
- 响应: `{"taskId": "xxx", "status": "SUCCESS", "results": [{"url": "COS链接", "outputType": "png"}]}`
- ⚠️ COS 链接 24h 失效，必须及时下载到本地

### 文件上传端点（图生图/视频需要参考图时用）
```
POST https://www.runninghub.cn/openapi/v2/media/upload/binary
```
- Header: `Authorization: Bearer [API KEY]`
- Form: `file=@/path/to/image.png`
- 响应: `{"data": {"download_url": "xxx.png"}}`（链接 1 天有效）

### 任务状态流转
`QUEUED(排队) → RUNNING(运行) → SUCCESS(成功)/FAILED(失败)`

## 分镜提示词标准模板（已验证）

### 六段式提示词结构

```text
subject_definitions:
<Picture 1> 严格负责[角色/场景]的身份与造型：[详细描述]
<Picture 2> 仅负责[场景/角色]的空间环境与机位参照：[详细描述]

summary:
[一句话概括整体剧情和情绪弧线]

retention_analysis:
人物不变量：[锁定要素]
场景不变量：[锁定要素]
风格不变量：[锁定要素]
绝对禁止：字幕、画面文字、LOGO、水印。

detailed_description:
[Shot 1]（0s-XXs）[镜头类型]，[机位]。[详细动作描述]。[对白内容]。
[如有多个镜头继续描述...]

overall_soundscape:
[环境音描述，分段说明]

non_diegetic_music:
[XX秒配乐轨，无歌词，情绪描述。按时间段说明音乐变化]
```

### 关键要点

1. **subject_definitions** 必须明确角色和场景的职责边界
2. **retention_analysis** 用"不变量"概念锁定关键元素
3. **detailed_description** 精确到秒的时间轴，包含机位、动作、对白
4. **overall_soundscape** 分段描述环境音
5. **non_diegetic_music** 按时间段描述音乐变化
