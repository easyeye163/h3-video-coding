## 1. 嵩口视觉风格 Token（Style Tokens）

### 1.1 环境关键词（中英）
- 建筑：白墙黛瓦（white walls & dark tiles）/ 马头墙（horse-head gables）/ 天井（sky wells）/ 夯土黄墙
- 自然：大樟溪（Dazhang Stream）/ 龙山（Longshan mountain）/ 晨雾（morning mist）/ 远山叠嶂
- 路面：青石板路（bluestone path）/ 鹤形石板（crane-pattern slabs）/ 鹅卵石（cobblestone）
- 道具：木雕门窗（carved wooden doors & windows）/ 红灯笼（red lanterns）/ 竹编（bamboo weaving）
- 氛围：岁月静谧（serene timelessness）/ 文化厚重（cultural weight）/ 烟火气（living warmth）

### 1.2 光影与时间
- 主光：暖橙金光（warm golden light）/ 丁达尔光束（god rays）/ 晨雾漫射（mist diffusion）
- 时间：清晨 6:30–7:30 / 午后 15:00–16:00 / 黄昏 17:30–18:30（黄昏为嵩口最具识别度）
- 天气：薄雾晴 / 阴雨青瓦（青瓦湿润后色彩饱和度↑）

### 1.3 镜头与质感
- 质感：**电影级 8K，写实质感**（cinematic 8K photorealistic）
- 色调：暖橙+青灰（warm orange + cool grey），统一 SLOG 风格低饱和
- 镜头：航拍俯瞰（aerial）/ 中景跟拍（medium tracking）/ 浅景深特写（shallow DOF close-up）
- 比例：16:9，24fps 电影感运镜

### 1.4 视觉不变量（V1 缺，V2 必须锁定）
- **绝对禁止**：字幕、画面内文字、LOGO、水印、UI 元素
- **建筑不变**：嵩口建筑为明清风格徽派/福建土楼混合，不出现现代玻璃幕墙、不出现西式洋楼
- **服装不变**：角色一旦定妆，所有镜头服装/发型/配饰一致（无换装、无变形）
- **手部正确**：六指/缺指/多余指节一律禁止；面部五官不扭曲
- **时代无穿越**：不出现手机/汽车/电瓶车/塑料制品（除非作为"现代人对比"道具并明确说明）

## 3. 嵩口 6 段式 Full-Reference 模板（V2）

```

  providing [建筑/光线/氛围] for the scene.

<Audio 2> is the voice-timbre reference for <Subject Y> (S2), [音色描述].

summary:
[reference generation + audio reference] The target video is a [时长]s cinematic 
  realistic [集名] scene of [Episode N: 标题], [一句话剧情]. 
  Set in [嵩口古镇·具体地点], [时段] light, [情绪]. 
  Uses <Picture 1> and <Picture 2> for visual consistency and 
  <Audio 1>/<Audio 2> for character voices. Full cinematic 8K, 
  warm-orange + cool-grey palette, no subtitles or on-screen text.

retention_analysis:
<Subject 1> ([Shot X]): fully_preserved - [面部/发型/服装] all retained.
<Picture 1> ([Shot X] first frame / reference): fully_preserved - visual anchor.
<Picture 2> ([Shot X] environment): fully_preserved - architectural & light reference.
<Audio 1>: reference - voice timbre guides S1 without copying the original signal.
<Audio 2>: reference - voice timbre guides S2 without copying the original signal.

  buildings, no on-screen text, 6-finger rule, no outfit change.

  and shallow depth of field.
[Shot 1] (0s-XXs) [镜头类型]，[机位]。[详细动作描述，包含环境、表情]。
  <Subject 1> (S1) says in a [音色] voice, <d>[Chinese] 台词</d>。
[Shot 2] At MM:SS.mmm, ...

overall_soundscape:

non_diegetic_music:
```
