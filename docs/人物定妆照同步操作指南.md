### 方法2：使用API自动下载（需要编程）

如果API支持结果查询，可以使用以下伪代码：

```python
import requests
import os

API_KEY = "你的API_KEY"
BASE_URL = "https://www.runninghub.cn/openapi/v2"
SAVE_DIR = "./images/songkou_characters"

tasks = [
    ("林小溪", "2092972777580744705"),
    ("陈阿公", "2092973318515949569"),
    ("张导演", "2092973403551260673"),
    ("神秘旅人", "2092973061623209985"),
    ("小糯米", "2092973651837284354"),
]

os.makedirs(SAVE_DIR, exist_ok=True)

for name, task_id in tasks:
    # 查询任务状态
    response = requests.get(
        f"{BASE_URL}/task/{task_id}",
        headers={"Authorization": f"Bearer {API_KEY}"}
    )
    
    if response.status_code == 200:
        data = response.json()
        if data.get("status") == "SUCCESS":
            # 下载图片
            image_url = data["results"][0]["url"]
            img_response = requests.get(image_url)
            
            filename = f"{name.lower()}_three_view.png"
            with open(os.path.join(SAVE_DIR, filename), "wb") as f:
                f.write(img_response.content)
            
            print(f"✅ {name} 下载完成")
```

## 💡 常见问题

### Q1：图片生成需要多长时间？
A：通常30-90秒，取决于服务器负载。

### Q2：如何确认图片是写实风格而非动漫？
A：检查图片是否具有：
- 真实的皮肤纹理（毛孔、血管等）
- 自然的光影过渡
- 照片级的细节质感
- 无明显线条勾勒或卡通化处理

### Q3：三视图可以用于哪些AI视频工具？
A：推荐用于：
- **RunningHub KREA-2-EDIT**（图生图，一致性最好）
- **AnimateDiff**（图生视频）
- **MiniMax H3**（作为视觉参考）
- **即梦**（作为提示词参考）

### Q4：如果对生成的图片不满意怎么办？
A：可以：
1. 调整提示词重新生成
2. 使用KREA-2-EDIT进行局部修改
3. 手动在PS中微调
