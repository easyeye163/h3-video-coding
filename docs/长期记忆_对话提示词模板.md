# 带对话的视频生成提示词模板

## 六段式结构（加入对话）

### 1. Subject Definitions
- 所有角色的外貌、服装、表情定义
- Audio1/Audio2 角色区分

### 2. Summary
- 一句话概括场景

### 3. Retention Analysis
- 开头/中段/结尾的情绪变化

### 4. Detailed Description
- **必须包含对话内容**
- 格式：`角色说："台词"`
- 包含表情和动作描述

### 5. Overall Soundscape
- 环境音 + 对话轨道说明

### 6. Non-diegetic Music
- 背景音乐风格

---

## 对话嵌入示例

### 示例1 - 相遇场景
```
现代女子（微笑）："你好，你是新来的吗？"
神秘女子（困惑）："这里……是哪里？"
```

### 示例2 - 解释场景
```
现代女子："这是21世纪的咖啡厅。"
神秘女子（惊讶）："21世纪？我在做梦吗？"
```

### 示例3 - 告别场景
```
神秘女子："我要回去了。"
现代女子："再见，朋友！"
```

## 多角色音频标记

| 标记 | 含义 | 使用位置 |
|------|------|----------|
| `[Audio1]` | 角色1说话 | Detailed Description |
| `[Audio2]` | 角色2说话 | Detailed Description |
| `[SFX]` | 环境音效 | Overall Soundscape |
| `[BGM]` | 背景音乐 | Non-diegetic Music |

---

## 注意事项

1. 对话要简短有力，每句不超过15字
2. 情绪标记要清晰：疑惑/惊讶/温暖/不舍
3. 场景转换时对话要自然衔接
4. Audio1/Audio2要性格分明
