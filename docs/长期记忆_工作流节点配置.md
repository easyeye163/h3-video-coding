## Seedance 视频生成工具（火山引擎 Ark API）

> 与 RunningHub 工作流并行使用的视频生成方案，支持文生视频、图生视频、参考音频等。

- **脚本**: `scripts/seedance_video.py`
- **文档**: `docs/seedance_video_README.md`（使用说明）、`docs/seedance_video_SKILL.md`（Skill定义）
- **API密钥**: 环境变量 `VOLCENGINE_ARK_API_KEY`
- **默认模型**: `doubao-seedance-1-5-pro-251215`（1.5专业版）
- **可用模型**: `doubao-seedance-2-0-260128`（2.0标准版，支持参考音频）、`doubao-seedance-2-0-fast-260128`（2.0快速版）

### 常用命令

```bash
# 文生视频
python3 scripts/seedance_video.py generate \
  --prompt "描述文本" --ratio 16:9 --duration 5

# 图生视频（首帧）
python3 scripts/seedance_video.py generate \
  --first-frame "https://cdn.jsdelivr.net/gh/.../scene.png" \
  --prompt "让画面动起来" --ratio adaptive --duration 5

# 首尾帧图生视频
python3 scripts/seedance_video.py generate \
  --first-frame "url1" --last-frame "url2" \
  --ratio adaptive --duration 5

# 参考图（全能参考）
python3 scripts/seedance_video.py generate \
  --reference-image "url1" --reference-image "url2" \
  --prompt "参考图1的主体做参考图2的动作" --ratio 16:9

# 参考音频（需2.0+模型）
python3 scripts/seedance_video.py generate \
  --model doubao-seedance-2-0-260128 \
  --first-frame "url" --reference-audio "voice_url" \
  --prompt "角色说：你好" --generate-audio

# 查询任务状态
python3 scripts/seedance_video.py status --task-id cgt-xxxxx
```

### 与 RunningHub 的对比

| 特性 | RunningHub (AnimateDiff) | Seedance (火山引擎) |
|------|--------------------------|---------------------|
| 文生视频 | 不支持 | 支持 |
| 图生视频 | 首帧 | 首帧+尾帧 |
| 参考图 | 角色/图片参考 | 全能参考（多图） |
| 参考音频 | 支持 | 支持（2.0+） |
| 生成质量 | 中等 | 高（电影级） |
| 生成速度 | 较慢 | 较快 |
| 时长 | 10秒 | 5-15秒 |
| 音频同步 | 需单独处理 | 原生支持 |

### 重要约定
- **图生视频优先使用 Seedance**：项目2（镇妖录）的场景视频优先用 Seedance 图生视频，效果更佳
- **空音频占位符同样适用**：无需台词时用 `audio/voices/silent_placeholder.mp3`
- **图片URL**：使用 jsDelivr CDN 链接 `https://cdn.jsdelivr.net/gh/easyeye163/h3-video-coding@main/...`
