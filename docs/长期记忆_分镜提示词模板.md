
# 分镜提示词标准模板

## 六段式结构

### 1. subject_definitions - 角色/场景定义
```
<Picture 1> 严格负责[角色/场景]的身份与造型：[详细描述面部、发型、服装、体态]
<Picture 2> 仅负责[场景/角色]的空间环境与机位参照：[详细描述环境、光线、布局]
```

### 2. summary - 剧情概述
```
一段XX秒真人实拍质感的[类型]戏。[一句话概括剧情和情绪]。[风格描述]。全片无字幕、禁止生成任何文字。
```

### 3. retention_analysis - 不变量锁定
```
人物不变量：[锁定要素]必须全程保持一致，不出现换装、变形、多余手指或五官扭曲。
场景不变量：[锁定要素]保持稳定，[动态元素]持续存在。
风格不变量：[质感、色调、氛围描述]。
绝对禁止：字幕、画面文字、LOGO、水印。
```

### 4. detailed_description - 分镜描述
```
[Shot 1]（0s-XXs）[镜头类型]，[机位]。[详细动作描述]。[对白内容]。[表情变化]。
```

### 5. overall_soundscape - 环境音
```
[环境音描述，分段说明不同镜头的声音]
```

### 6. non_diegetic_music - 配乐
```
XX秒配乐轨，无歌词，[情绪描述]。按时间段说明音乐变化。
```

## 关键要点

1. **职责分离**：明确Picture 1和Picture 2的不同职责
2. **不变量锁定**：用"不变量"概念防止AI漂移
3. **时间轴精确**：分镜描述精确到秒
4. **声音同步**：环境音和配乐与画面精确配合
5. **禁止项明确**：列出所有禁止生成的元素

## 示例（海边度假场景）

```
subject_definitions:
<Picture 1> 严格负责场景环境：热带海滩度假场景，白天阳光明媚...
<Picture 2> 严格负责女性角色的身份与造型：年轻漂亮的东方女性...

summary:
一段10秒真人实拍质感的度假vlog场景...

retention_analysis:
人物不变量：图2女性的面部、黑发、服装必须全程一致...
场景不变量：图1的海滩布局、海水位置保持稳定...
风格不变量：真人实拍质感，热带度假风...
绝对禁止：字幕、画面文字、LOGO、水印。

detailed_description:
[Shot 1]（0s-10s）海滩中景，[Static shot] 固定机位...

overall_soundscape:
海浪持续轻拍沙滩的节奏声...

non_diegetic_music:
10秒配乐轨，无歌词，清新度假vlog...
```
