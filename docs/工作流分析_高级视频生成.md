## 提示词结构（黄金公式）

### 1️⃣ subject_definitions - 角色定义
- 明确区分角色和场景的职责边界
- Picture 1: 专注角色造型
- Picture 2: 专注场景环境

### 2️⃣ summary - 场景概述
- 一句话概括整体情绪弧线
- 明确视频类型和风格

### 3️⃣ retention_analysis - 不变量分析
- 人物不变量：面部、发型、服装、体型
- 场景不变量：布局、位置、光线
- 风格不变量：质感、色调、氛围
- 绝对禁止：字幕、文字、LOGO、水印

### 4️⃣ detailed_description - 分镜描述（核心）
- 精确到秒的时间轴
- 机位、构图、运动详细描述
- 情绪变化的具体节点
- 对白的具体内容
- 表演细节（微表情、肢体动作）

### 5️⃣ overall_soundscape - 环境音设计
- 与画面同步的环境音
- 对白期间的声音层次
- 不同镜头的声音设计

### 6️⃣ non_diegetic_music - 配乐设计
- 无歌词配乐
- 与情绪变化精确同步
- 分段描述音乐变化

## 关键技巧总结

| 技巧 | 说明 |
|------|------|
| 职责分离 | Picture 1专注角色，Picture 2专注场景 |
| 不变量锁定 | 用"不变量"概念避免AI漂移 |
| 时间轴精确 | 分镜描述精确到秒 |
| 情绪弧线 | 明确的情绪变化节点 |
| 声音同步 | 环境音和配乐与画面精确配合 |
| 表演细节 | 描述具体的微表情和肢体动作 |
