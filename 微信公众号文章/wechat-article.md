## 一、项目背景

最近很多创作者在问：**如何快速生成高质量的AI短视频？**

传统的做法需要：
- 先用Midjourney/Stable Diffusion生成底图
- 再用Runway/Pika做视频化
- 最后剪映加字幕配音

整个过程耗时数小时，且需要多个平台切换。

今天我用**DeepSeek Harness + RunningHub + Agnes智能体**，用一套完整工作流，在20分钟内完成了从文生图→图片编辑→视频生成的全链路，最终产出一条带口播配音的电影级短视频。

## 二、完整工作流拆解

整个项目分为三个核心步骤，每个步骤调用不同的AI工作流：

### Step 1：Z-image 文生图
**App ID**: `2088920592350277634`

首先用Z-image生成基础图像。这个模型的特点是**完美支持中文字符**，能够精准理解中文提示词。

**提示词**（部分）：
```
电影级 8K 超清，写实氛围感，年轻精致东方少女，
黑色长卷发，通透冰蓝色眼眸，柔和水光妆容，
身穿半透薄荷绿色薄纱长裙...
```

**结果**：生成了一张符合要求的电影级人像图。

---

### Step 2：KREA-2-EDIT 图片编辑
**App ID**: `2088926295186034689`

接下来需要对生成的图片进行修改——将薄荷绿色裙子改为紫色。

KREA-2-EDIT 的优势在于**人物一致性超高**，特别适合作为短剧、角色换装等场景。

**输入参数**：
- `text`: "把衣服改成紫色"
- `image`: 上一步生成的图片URL

**结果**：裙子成功替换为紫色，人物面部特征、姿态完全保持一致。

---

### Step 3：AnimateDiff 视频生成
**App ID**: `2088844222551121921`

最后一步是将静态图片转化为动态视频，并添加口播配音。

这一步需要构造详细的英文提示词，描述：
- 画面内容（人物、服饰、环境）
- 镜头运动（缓慢推进）
- 人物表情和动作
- **中文口播内容**

**修改后的中文台词**：
```
<d>[Mandarin Chinese] 欢迎关注gc随笔，
智能体结合工作流真的很好用。</d>
```

**结果**：生成了一段10秒的电影级短视频，人物嘴型与台词同步。

## 三、为什么选择 Agnes 智能体？

在整个工作流中，我使用了 **Agnes（agnes-2.5-flash）** 作为执行智能体。选择它的原因如下：

### 1. 指令执行准确
Agnes 能够准确理解并执行复杂的API调用指令，包括：
- 构造正确的JSON请求体
- 处理中文转义问题
- 自动重试失败的任务

### 2. 工作流编排能力
通过多次对话，Agnes 能够：
- 理解上游任务的输出
- 将结果传递给下游任务
- 自动查询任务状态

### 3. 错误处理能力
当遇到显存不足（OOM）时，Agnes 能够：
- 识别错误码
- 自动切换实例类型（default → plus）
- 重新提交任务

### 4. 成本意识
Agnes 能够记录每一步的消耗，并在任务完成后汇总：
```
总计消耗：157 RH币
- 文生图：13 RH币
- 图片编辑：15 RH币
- 视频生成：129 RH币
```

## 六、进阶玩法：本地运行，无限创作

### 担心RH币不够用？

RunningHub 提供了**工作流导出**功能，可以将线上验证过的工作流导出为本地配置文件。

### 本地运行优势

1. **零成本无限创作**
   - 本地部署ComfyUI，无需消耗RH币
   - 只要有显存，想生成多少就生成多少

2. **完全可控**
   - 模型版本自己选择
   - 参数调整更灵活
   - 数据安全私密

3. **无缝迁移**
   ```bash
   # 导出工作流
   RunningHub → 工作流详情 → 导出JSON
   
   # 本地导入运行
   ComfyUI Manager → Import → 选择导出的JSON
   ```

### 建议的工作模式

```
线上验证 → 参数调优 → 本地批量生产
```
