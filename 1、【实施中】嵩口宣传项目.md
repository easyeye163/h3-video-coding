## 五、技术工作流配置（RunningHub API）

### 5.1 API 基础

- **端点**：`POST https://www.runninghub.cn/openapi/v2/run/ai-app/{appId}`
- **认证**：`Authorization: Bearer {RUNNINGHUB_API_KEY}`（环境变量）
- **请求体**：`{"nodeInfoList":[{"nodeId":"","fieldName":"","fieldValue":""}],"instanceType":"default","usePersonalQueue":"false"}`
- **响应**：返回 `taskId`，用查询接口轮询状态

### 5.2 短剧必备工作流（节点配置以《长期记忆_工作流节点配置.md》为准，已实测验证）

| 工作流 | App ID | 用途 | 关键节点 |
|---|---|---|---|
| Z-image 文生图 | `2088920592350277634` | 场景图/概念图（支持中文） | nodeId `17` = prompt |
| KREA-2-EDIT 图生图 | `2088926295186034689` | 角色三视图（人物一致性） | nodeId `1` = prompt（图片节点需查控制台） |
| AnimateDiff 单图视频 | `2088844222551121921` | 文/图生视频 | `137`首帧 / `138`提示词 / `157`参考音频 / `156`角色参考 / `165`Audio参考 / `166`Picture2参考 / `132`时长(10) / `115`比例分辨率 |
| 多图像视频生成 | `2088878767828717570` | 多参考视频 | `137`首帧 / `157`参考音频 / `156`角色参考 / `138`提示词（顺序重要） |
| 音频生成 | `2090440149267210242` | 角色配音 | `3`声音设计提示词 / `5`TTS文本 |

> ⚠️ 早期文档（如《人物定妆照同步操作指南.md》）记录的 KREA-2-EDIT 节点为 `160`=text/`104`=image，与最新验证的 `1`=prompt 不一致；以本表为准，调用前建议在控制台二次确认节点ID。

### 5.3 调用注意事项

1. **JSON 中文引号**：提示词中的中文引号需转义或改用英文引号，否则字段校验失败
2. **并发限制**：同时提交多任务会失败，关键任务串行处理，每次调用后 `sleep(10)`
3. **COS 链接 24h 失效**：RunningHub 返回的云端链接 24 小时失效，成片必须及时下载到本地 `videos/songkou_drama/` 或 `images/songkou_characters/`，主文档只记本地路径
4. **instanceType 选择**：视频生成显存消耗大，默认 `default`，视频任务建议 `plus`（48G 显存）
5. **字段类型**：飞书单选字段必须用数组格式如 `["文生图"]`，否则批量创建校验失败
6. **优先用 Token**：图片输入优先用 File Token 而非 URL，飞书云盘 URL 无法直接被 API 访问
